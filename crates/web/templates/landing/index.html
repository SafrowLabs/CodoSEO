CI/CD

Fail the build before rankings drop.

CodoSEO is one static binary with no browser and no config file, so it drops into any pipeline. --fail-on critical exits with code 1 when the threshold is reached.

Fast and politeAsync crawling in Rust that still respects robots.txt and Crawl-delay, and backs off on 429 and 503.
Exit codes for CIGate a deploy on critical or warning findings, for crawls and for diffs.
Plain outputTable, JSON, Markdown and CSV. Audit files are portable and diffable.

- name: SEO audit
  run: |
    cargo install codoseo
    codoseo crawl {% raw %}${{ env.SITE_URL }}{% endraw %} \
      --format json -o audit.json \
      --fail-on critical

# later: compare against the last release
- name: SEO diff
  run: codoseo diff before.json audit.json --fail-on critical

FAQ

Questions, answered.

Something else on your mind? Open an issue on GitHub and we'll get back to you.

Is CodoSEO free?

Yes. The CLI, the MCP server and the self-hosted web app are free and open source under AGPL-3.0. The hosted app has a free plan for one site. Paid plans for more sites and bigger crawls are coming soon.

Do I need an account?

Not for the CLI or the local MCP server, and not for a one-off audit of up to {{ quick_pages }} pages in the hosted app. A free account lets you monitor a site on a schedule and get alerts.

How do I install the CLI?

Run brew install safrowlabs/codoseo/codoseo, npx codoseo, or cargo install codoseo (Rust 1.88 or newer). Prebuilt binaries for Linux, macOS and Windows are on the GitHub releases page, and a Docker image is at ghcr.io/safrowlabs/codoseo.

What does CodoSEO check?

{{ checks }} checks across {{ categories.len() }} categories: response codes and redirects, indexability (noindex, canonicals, robots.txt), on-page (titles, meta descriptions, H1s), content (thin and duplicate pages, image alt text), links (broken links, orphan pages, click depth), technical (HTTPS, mixed content, slow responses), sitemaps, Open Graph and structured data (JSON-LD, hreflang).

Will crawling slow down my site?

CodoSEO is built to be polite. It obeys robots.txt and Crawl-delay, slows down on its own when a server answers 429 or 503, and identifies itself as CodoSEObot so you can spot it in your logs.

Does it work with AI assistants?

Yes. CodoSEO includes an MCP server. Run codoseo mcp on your machine, or connect the hosted server at {{ base }}/mcp, and Claude, Cursor or any MCP client can run audits and read the results.

Can I self-host the web app?

Yes. Docker Compose brings it up in three commands and it needs nothing but Postgres. The self-hosting guide covers email, sign-in, reverse proxies, upgrades and backups.
