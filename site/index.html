Why CodoSEO

Everything you need
to audit a site.

A single binary that crawls, checks, scores and diffs — with no browser, no headless Chrome, no configuration files.

🦀
Fast Rust crawler
Async, polite and memory-flat. Crawls 500 pages in seconds. Respects robots.txt, Crawl-delay and backs off on 429/503.
✅
44 SEO checks
Across 9 categories: response, indexability, on-page, content, links, technical, sitemap, social and schema. Critical · Warning · Notice severities.
📊
Health score 0–100
Weighted by severity and the fraction of affected pages. A site where every page fails every check scores 0. No failures scores 100.
🔄
Audit diff
Compare two saved JSON audits. Surfaces new issues, resolved issues, score changes, status changes, title changes and redirect regressions.
🚀
CI-ready
--fail-on critical exits 1. Pipe into GitHub Actions, GitLab CI or any shell script. Fail the build before rankings drop.
📄
Multiple output formats
Table, JSON, Markdown and CSV. Pipe JSON into jq, export CSV to a spreadsheet, or save Markdown as a report.

44 checks across 9 categories

Nothing slips through.

Every crawled page is evaluated for response health, indexability, on-page quality, content issues, link problems and more.

📄
