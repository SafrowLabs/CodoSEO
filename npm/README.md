# CodoSEO

CodoSEO is an SEO crawler and site auditor for the command line.

```sh
npm install -g codoseo
codoseo crawl https://example.com
```

The npm package downloads the matching CodoSEO binary from the GitHub release for the package version. Supported platforms are Linux x64 and arm64, macOS x64 and arm64, and Windows x64.

For local development, set `CODOSEO_BINARY` to a compiled binary or set `CODOSEO_SKIP_DOWNLOAD=1` and make `codoseo` available on `PATH`.

Project documentation: <https://github.com/SafrowLabs/codoSEO>
